# MAX Group Inviter

Десктопное приложение для массового добавления пользователей в группу
мессенджера **MAX** через **GREEN API**. Получатели импортируются из Excel.

UI спроектирован в духе Apple HIG: пошаговый мастер, кардовая раскладка,
типографическая иерархия, системные цвета и адаптивная светлая/тёмная тема.

## Поток

```
1. Welcome    →   2. Подключение   →   3. Группа   →   4. Получатели   →   5. Рассылка
```

Сайдбар-степпер показывает прогресс, текущий и завершённые шаги. По уже
пройденным шагам можно вернуться кликом.

## Что внутри

- **Welcome** — краткое описание, перечень возможностей.
- **Подключение** — `idInstance`, `apiTokenInstance`, базовый URL, задержка;
  кнопка «Проверить» выполняет `getStateInstance` и показывает состояние
  цветной пилюлей.
- **Группа** — ID группы, кнопка «Получить данные группы» вызывает
  `getGroupData` и отображает название и количество участников.
- **Получатели** — выбор `.xlsx`, генерация шаблона, таблица с превью.
  Колонки и формат телефонов определяются автоматически
  (`+7 (xxx)` → `7xxxxxxxxxx@c.us`, `8…` → `7…`).
- **Рассылка** — сводка (группа, кол-во, задержка), полоса прогресса,
  список со статусами по каждому получателю, журнал, остановка.

## Установка и запуск

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
python app.py
```

## Формат Excel-файла

| Имя           | Телефон             |
|---------------|---------------------|
| Иван Иванов   | +7 900 123-45-67    |
| Мария Петрова | 79161234567         |
| …             | 8 (905) 555-12-34   |

- Заголовок (первая строка) необязателен.
- Колонка с телефонами определяется автоматически по содержимому.
- Можно сгенерировать стилизованный шаблон прямо из приложения.

## Структура проекта

```
app.py                   # тонкий entry-point
core/                    # бизнес-логика, без UI
  green_api.py           # HTTP-клиент GREEN API (maxInstance…)
  excel.py               # чтение и шаблон Excel
  settings.py            # ~/.max_group_inviter.json
  state.py               # AppState, разделяемое состояние
  worker.py              # фоновый воркер рассылки + события
ui/                      # UI-слой
  theme.py               # дизайн-система (цвета, типографика, spacing)
  components.py          # Card, Pill, FieldRow, Stepper, кнопки…
  window.py              # главное окно: сайдбар + роутинг шагов
  views/
    welcome.py
    connection.py
    group.py
    users.py
    send.py
README.md
requirements.txt
```

## Дизайн-система

Все цвета и шрифты вынесены в `ui/theme.py` — поменять акцент или
типографику можно в одном месте.

| Токен              | Назначение                                  |
|--------------------|---------------------------------------------|
| `BG_PAGE`          | фон страницы (нейтральный нейтральный сер.) |
| `BG_SIDEBAR`       | сайдбар (контрастная плоскость)             |
| `BG_CARD`          | карточки                                    |
| `BG_CARD_INSET`    | утопленные блоки (журнал, таблица)          |
| `ACCENT`           | системный синий                             |
| `SUCCESS / WARN / DANGER` | семантические цвета пилюль и статусов |
| `R_LG / R_MD / R_SM` | радиусы скругления                        |
| `SP_2…SP_7`        | спейсинг по шкале 8/12/16/24/32/48          |

Типографика подбирается лениво из шкалы «SF Pro → Inter → Segoe UI Variable
→ Helvetica → Arial» с автодетектом доступных семейств.

## Безопасность

Все настройки и токен хранятся локально в `~/.max_group_inviter.json`.
Поле токена в интерфейсе маскируется. Не коммитьте файл с токеном.

## API-конвенция

Эндпоинт строится как
`{apiUrl}/maxInstance{idInstance}/{method}/{apiTokenInstance}`.
Если в вашем тарифе MAX-инстанс называется иначе, измените
`instance_prefix` в `core/green_api.py`.
