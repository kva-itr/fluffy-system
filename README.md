# MAX Group Inviter

Десктопное приложение с современным интерфейсом для массового добавления
пользователей в группу мессенджера **MAX** через **GREEN API**.

Список пользователей загружается из Excel-файла.

## Возможности

- Красивый интерфейс на CustomTkinter (тёмная / светлая / системная тема).
- Загрузка пользователей из `.xlsx` (имя + телефон).
- Автоматическое распознавание колонок и нормализация телефонов
  (`+7 (900) 123-45-67` → `79001234567@c.us`, `8XXX…` → `7XXX…`).
- Проверка подключения к GREEN API (`getStateInstance`).
- Пакетное добавление с настраиваемой задержкой между запросами.
- Прогресс-бар, статус по каждому пользователю, журнал операций.
- Кнопка остановки и подтверждение перед запуском.
- Сохранение настроек (ID инстанса, токен, URL, ID группы, задержка)
  в `~/.max_group_inviter.json`.
- Генерация Excel-шаблона прямо из приложения.

## Установка

Требуется Python 3.10+.

```bash
pip install -r requirements.txt
python app.py
```

## Формат Excel-файла

Первый лист, первые две колонки:

| Имя           | Телефон             |
|---------------|---------------------|
| Иван Иванов   | +7 900 123-45-67    |
| Мария Петрова | 79161234567         |
| Алексей …     | 8 (905) 555-12-34   |

- Заголовок (первая строка) необязателен.
- Колонка с телефонами определяется автоматически, если её название
  отличается от стандартного.
- Можно сгенерировать готовый шаблон кнопкой **«Создать шаблон»**.

## Настройки GREEN API

В сайдбаре заполните:

| Поле          | Где взять                                                          |
|---------------|--------------------------------------------------------------------|
| **ID инстанса** | Личный кабинет GREEN API → ваш инстанс MAX → `idInstance`          |
| **API Token**   | Личный кабинет GREEN API → ваш инстанс MAX → `apiTokenInstance`    |
| **ID группы**   | ID групповой беседы в MAX (можно получить через `getChats` API)    |
| **API URL**     | По умолчанию `https://api.green-api.com`                           |
| **Задержка**    | Пауза между добавлениями (рекомендуется ≥ 1.5 с, чтобы не упереться в лимиты) |

Приложение использует эндпоинт
`{apiUrl}/maxInstance{idInstance}/addGroupParticipant/{apiToken}`.
Если в вашем тарифе MAX-инстанс называется иначе, отредактируйте поле
`instance_prefix` в `green_api_client.py`.

## Безопасность

Токен хранится локально (`~/.max_group_inviter.json`) и в поле ввода
маскируется. Не коммитьте файл с токеном.
